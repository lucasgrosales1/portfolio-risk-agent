# Hero image

Drop a photo here named **`hero.jpg`** (or `hero.png` / `hero.webp`) and it will
appear in the Home page hero automatically, replacing the coastal graphic.

Use a photo you have the rights to — your own family photo is ideal, or a
properly-licensed stock photo. Landscape orientation, roughly 3:2, looks best.

Recommended: 1200×800 px or similar. Keep the file under a few hundred KB so the
page loads fast (the image is embedded inline).

# Advisor headshot

Drop a headshot named **`advisor.jpg`** (or `.png` / `.webp`) and it will appear
in the "Our team" section on the Home page, replacing the initials monogram.
Square, roughly 400×400 px, works best. Use a photo you have the rights to.
